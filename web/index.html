    Where calls come from

    Add a source the tool does not read yet

    Every funder page, feed and API this tool reads. Each shows when it last worked, so a source that has quietly stopped yielding is visible rather than silent.

    Added sources are kept separately from config/sources.yaml, which stays the reviewed baseline, and are merged with it on the next ingest. A URL already covered by either list is refused rather than added twice: the same funder under two names would be fetched twice and each copy would report itself healthy.
